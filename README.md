# treverjackson.com

Personal site. Hosted on Cloudflare Pages.

## Deploy

```bash
wrangler pages deploy ./ --project-name=treverjackson
```

## Local preview

Just open `index.html` in a browser — it's a static single-page site with no build step.

Or use wrangler's local dev:

```bash
wrangler pages dev ./
```
